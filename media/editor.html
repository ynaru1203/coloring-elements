Coloring Elements

C# 코드의 색상을 설정합니다. 색상 선택을 확정하면 자동 저장됩니다. 드래그 중에는 에디터 설정을 변경하지 않습니다.

속성 조합 (체크한 조건을 모두 만족)

설명을 보려면 항목 위에 마우스를 올려 두세요. ‘선택한 식별자 감지’를 누르면 해당 조건이 자동으로 체크됩니다.

초기화하면 선택한 범위의 foreground만 제거합니다. 상위 범위·더 구체적인 규칙·테마별 규칙이 있으면 그 색상이 적용됩니다. 글꼴 스타일은 유지합니다.

저장된 C# 색상 규칙

    가져오기는 같은 조건의 색상을 덮어씁니다. 분류 방식별 규칙은 따로 저장됩니다. 정밀 규칙은 조건이 많은 순서, 요소를 지정한 순서로 우선하며 동점이면 규칙 ID의 사전순으로 정합니다. 정밀 규칙이 없으면 기존 강조를 유지합니다. VS Code 검사기는 기본 분류의 색상을 확인하는 도구입니다.
